# Spec Delta

## MODIFIED Requirements

### Requirement: 模型请求内容
模型请求 SHALL 携带可选的 system prompt、本次调用截至发起时的完整有序线程事件快照、可用工具规格和迭代序号，以 `events` 替代 `history` 字段。不允许使用工具时，工具规格 MUST 为空。除独立的 system prompt 外，模型输入提示 MUST 来源于事件快照，MUST NOT 通过独立 history 或隐藏的提醒旁路注入。快照 SHALL 包含本次请求前已记录的全部提醒事件，其中哪些提醒送达由会话投影的消费规则决定。

#### Scenario: 强制收尾请求
- **WHEN** 系统发起超限后的强制收尾调用
- **THEN** 请求的工具规格为空，事件快照包含此次调用前记录的收尾提醒事件，格式化后的消息以有效的收尾提醒结尾

#### Scenario: 跨回合事件快照
- **WHEN** 同一线程在第二个回合发起模型请求
- **THEN** 请求包含此前回合及当前回合截至本次调用的全部事件，并保持日志顺序，调用后的事件不改变该请求快照

#### Scenario: 空事件请求
- **WHEN** 调用方构造没有对话事件的模型请求
- **THEN** 请求允许携带空事件列表，system prompt 和工具规格仍独立保留

#### Scenario: 模型前写入的提醒进入本次快照
- **WHEN** 模型前钩子在某次请求前写入一条提醒
- **THEN** 该请求的事件快照以日志顺序包含该提醒事件，格式化后的消息以该提醒结尾
