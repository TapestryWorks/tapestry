# Spec Delta

## ADDED Requirements

### Requirement: 流式模型输出
模型客户端 SHALL 支持以流的形式返回一次调用的结果：先是零个或多个文本增量，最后恰好一个完整的模型响应。不支持流式的客户端 SHALL 只产生最终响应。完整响应 MUST 携带本次调用的全部工具调用和 token 用量。

#### Scenario: 默认实现
- **WHEN** 一个只实现了一次性调用的模型客户端被以流式方式调用
- **THEN** 流中只有一个完整响应，其内容与一次性调用的结果相同

#### Scenario: 流在完整响应后结束
- **WHEN** 消费方读取流式输出直到结束
- **THEN** 最后一个输出项是完整响应，之后没有其他输出

#### Scenario: 流式输出项可序列化
- **WHEN** 序列化并反序列化文本增量和完整响应两种输出项
- **THEN** 结果与原值相等，标签为 snake_case
